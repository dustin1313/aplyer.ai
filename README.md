# Aplyer.ai

**Stop Skipping Jobs.**

Aplyer is a Chrome extension that automatically activates on company careers pages (Workday, Greenhouse, Lever) and fills open-ended essay questions in the candidate's own voice using their resume and writing samples. Built for the 92% of job applicants who abandon applications because the process is too long or complicated.

## The Problem
Job seekers close the tab when they see essay questions. Not because they are unqualified — because the friction is too high. Aplyer removes that friction entirely.

## What It Does
- Detects essay questions automatically on careers pages — no manual trigger
- Generates voice-matched answers using the candidate's resume and writing samples
- Shows three confidence indicators: Voice Match, Low AI Signature, Uses Real Experience
- Logs every application automatically
- Works on Workday, Greenhouse, and Lever (MVP)

## Tech Stack (in development)
- Chrome Extension (Manifest V3)
- JavaScript / HTML / CSS
- Anthropic Claude API for answer generation
- Stripe for payments
- Free tier + paid subscription model
